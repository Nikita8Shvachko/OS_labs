# Лабораторная работа №2: Межпроцессное взаимодействие (IPC)

**Вариант 20**: Независимые процессы, архитектура "Один ко многим".

### Поддерживаемые типы IPC
1.  **MQ**: POSIX Message Queues (`host_mq`, `client_mq`)
2.  **FIFO**: Named Pipes (`host_fifo`, `client_fifo`)
3.  **Sock**: Unix Domain Sockets (`host_sock`, `client_sock`)

---

## Сборка и Запуск

Проект требует Linux (или Docker контейнер).

### 1. Сборка
```bash
./build.sh
```

### 2. Запуск (пример для MQ)
Нужны разные терминалы для Хоста и Клиентов.

**Терминал 1 (Хост):**
```bash
./build/host_mq
```
Скопируйте PID хоста (например, 1234).

**Терминал 2 (Клиент 1):**
```bash
./build/client_mq 1234
```
*(Вместо `mq` можно использовать `fifo` или `sock`)*

**Терминал 3 (Клиент 2):**
```bash
./build/client_mq 1234
```

*(Аналогично для `fifo` и `sock`)*

## Команды чата

*   `Привет всем` — отправить сообщение всем (Broadcast).
    *   Лог: `[1] -> [all] Привет всем`
*   `@2 Привет` — личное сообщение клиенту с ID 2.
    *   Лог: `[1] -> [2] Привет`
*   `@0 Сообщение админу` — личное сообщение Хосту.
    *   Лог: `[1] -> [0] Сообщение админу`
*   `/quit` — выход из чата.

## Особенности реализации
*   **Handshake**: Двусторонний обмен сигналами `SIGUSR1`. Хост передает ID клиенту через `sigqueue`.
*   **Timeout**: Клиенты, неактивные более 60 секунд, отключаются хостом (`SIGKILL`).
*   **Exit**: Выход по команде `/quit` с уведомлением хоста.
*   **Синхронизация**: Использование глобальных семафоров и timed-wait вызовов (5 секунд) для всех операций ожидания.
